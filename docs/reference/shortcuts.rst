Keyboard shortcuts
==================

A short list of the shortcuts you reach for most. The menus show the others, and the
full set evolves with the software.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Shortcut
     - Action
   * - ``Ctrl`` + ``Space``
     - Magnify the focused window (toggle full-area, and back)
   * - ``Esc``
     - Leave a folded group's space; dismiss an open menu or dialog
   * - ``Ctrl`` / ``Cmd`` + ``Z``
     - Undo (the document keeps a bounded history)
   * - ``Ctrl`` / ``Cmd`` + ``Shift`` + ``Z``
     - Redo
   * - ``Ctrl`` / ``Cmd`` + ``S``
     - Save the study to ``.em.json``
   * - scroll wheel
     - Zoom the graph canvas; drag empty canvas to pan

Mouse gestures in the graph — dragging a node, dragging from a node's edge to
connect, double-clicking a group to enter it — are described in
:doc:`../how-to/interpret-in-graph`.
